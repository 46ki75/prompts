Best-effort answer (unverified):

Amazon Bedrock AgentCore is a set of AWS services for building, deploying, and operating AI agents in production. It was announced at AWS Summit New York in July 2025 (in preview) and is aimed at running agents at enterprise scale, independent of which model or agent framework you use (e.g., Strands Agents, LangGraph, CrewAI, and others) — not limited to models hosted in Amazon Bedrock.

What it's for: it provides the surrounding infrastructure and operational "plumbing" that agents need beyond the LLM call itself, so teams don't have to build that scaffolding themselves. The capabilities I recall being grouped under it include:

- AgentCore Runtime — a serverless, isolated runtime for deploying and scaling agents, with support for long-running sessions.
- AgentCore Memory — managed short-term and long-term memory for agents across sessions.
- AgentCore Identity — identity and access management for agents, including secure access to AWS resources and third-party services/tools.
- AgentCore Gateway — turns existing APIs and services (and Lambda functions) into agent-usable tools, with MCP support.
- AgentCore Browser — a managed, sandboxed headless browser tool so agents can interact with websites.
- AgentCore Code Interpreter — a sandboxed environment for agents to execute code.
- AgentCore Observability — tracing, monitoring, and debugging of agent behavior.
