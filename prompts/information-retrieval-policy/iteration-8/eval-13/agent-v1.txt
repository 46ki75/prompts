Array.prototype.flat

`flat()` creates a new array with all sub-array elements recursively concatenated into it up to a specified depth. It does not mutate the original array.

- Signature: `arr.flat(depth)`
- `depth` (optional) defaults to `1`. Pass `Infinity` to flatten all nested levels.
- Empty slots in sparse arrays are removed.

Examples:
- `[1, [2, 3]].flat()` -> `[1, 2, 3]`
- `[1, [2, [3, [4]]]].flat(2)` -> `[1, 2, 3, [4]]`
- `[1, [2, [3, [4]]]].flat(Infinity)` -> `[1, 2, 3, 4]`

It was standardized in ES2019. (Stable language-spec behavior.)
