## Errors

### 1. ⚠️ Error

```diff
- a user click the button
+ a user clicks the button
```

Subject-verb agreement; the singular subject `a user` takes `clicks`.

### 2. ⚠️ Error

```diff
- the request are send
+ the request is sent
```

Singular subject `the request` takes `is`, and the passive requires the past participle `sent`, not `send`.

### 3. ⚠️ Error

```diff
- without no delay
+ without delay
```

Double negative; `without` already conveys the negation, so `no` is dropped.
