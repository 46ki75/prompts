## Errors

### 1. ⚠️ Error

```diff
- When a user click the button
+ When a user clicks the button
```

Subject-verb agreement; singular `a user` takes `clicks`.

### 2. ⚠️ Error

```diff
- the request are send
+ the request is sent
```

Two slips: singular `the request` takes `is` (agreement), and the passive voice requires the past participle `sent`, not the bare `send`.

### 3. ⚠️ Error

```diff
- without no delay
+ without delay
```

Double negative; standard English uses `without delay` (or `with no delay`), not both negatives together.
