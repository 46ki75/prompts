## Errors

### 1. ⚠️ Error

```diff
- a user click the button
+ a user clicks the button
```

Subject-verb agreement; singular `a user` takes `clicks`.

### 2. ⚠️ Error

```diff
- the request are send
+ the request is sent
```

Singular `the request` takes `is`, and the passive requires the past participle `sent`.

### 3. ⚠️ Error

```diff
- without no delay
+ without delay
```

Double negative; `without no` should be `without` (or `with no`).
