## Errors

### 1. ⚠️ Error

```diff
- a user click the button
+ a user clicks the button
```

Subject-verb agreement; the singular subject `a user` takes `clicks`.

### 2. ⚠️ Error

```diff
- the request are send
+ the request is sent
```

`request` is singular (`is`), and the passive voice requires the past participle `sent`.

### 3. ⚠️ Error

```diff
- without no delay
+ without any delay
```

Double negative; `without no` is ungrammatical. Use `without any delay` (or `with no delay`).
