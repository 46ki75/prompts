## Errors

### 1. ⚠️ Error

```diff
- a user click
+ a user clicks
```

Subject-verb agreement; singular `a user` takes `clicks`.

### 2. ⚠️ Error

```diff
- the request are send
+ the request is sent
```

`request` is singular (`is`), and the passive needs the past participle `sent`.

### 3. ⚠️ Error

```diff
- without no delay
+ without any delay
```

Double negative; use `without any delay` (or `with no delay`).
