## Errors

### 1. ⚠️ Error

```diff
- When a user click the button
+ When a user clicks the button
```

Subject-verb agreement; singular `a user` takes `clicks`.

### 2. ⚠️ Error

```diff
- the request are send to the server
+ the request is sent to the server
```

Singular subject `the request` takes `is`, and the passive requires the past participle `sent`.

### 3. ⚠️ Error

```diff
- without no delay
+ without delay
```

Double negative; `without` already carries the negation.
