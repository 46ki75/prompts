Based on training data through my cutoff, not freshly verified: Toasty is an asynchronous ORM for Rust, originally announced by Carl Lerche (of Tokio fame). It targets both SQL databases (e.g., SQLite, PostgreSQL) and NoSQL stores like DynamoDB through a unified schema and query API, with code generation from a schema file. At announcement it was explicitly pre-alpha / not production-ready.
