`Array.prototype.flat(depth = 1)` returns a new array with all sub-array elements concatenated into it recursively up to the specified depth. Empty slots in sparse arrays are removed. Pass `Infinity` to fully flatten an arbitrarily nested array. It does not mutate the original.

Example:
```js
[1, [2, [3, [4]]]].flat();        // [1, 2, [3, [4]]]
[1, [2, [3, [4]]]].flat(2);       // [1, 2, 3, [4]]
[1, [2, [3, [4]]]].flat(Infinity); // [1, 2, 3, 4]
```
