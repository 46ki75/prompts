`Array.prototype.flat([depth])` returns a new array with all sub-array elements concatenated into it recursively up to the specified `depth` (default `1`). It does not mutate the original array, and empty slots in sparse arrays are discarded. Use `Infinity` as the depth to fully flatten an arbitrarily nested array.

Examples:
- `[1, [2, 3]].flat()` — `[1, 2, 3]`
- `[1, [2, [3, [4]]]].flat(2)` — `[1, 2, 3, [4]]`
- `[1, [2, [3, [4]]]].flat(Infinity)` — `[1, 2, 3, 4]`
